# agents-tests

各模型、各版本的测试归档。首页是总索引，打开就能看到全部测试并直接进入。

## 项目说明

每条测试有两个文件：一个可打开的页面，一份同名记录。记录里写下每一轮的输入提示词，以及该轮 agent 回复的简要结果。

首页 `index.html` 一次列出全部模型、版本、日期和测试，可以排序和过滤。

## 项目愿景

不同人、不同模型、不同版本做出的测试放在同一处。后来的人不用翻对话，从首页就能找到某一天的某一条，并看到当时问了什么、答了什么。

## 项目规范

路径：

```
模型/版本/YYYYMMDD/测试名.(unix秒).html
模型/版本/YYYYMMDD/测试名.(unix秒).md
```

示例：

```
grok/4.7/20260922/qin-shihuang-assembly.1790011920.html
grok/4.7/20260922/qin-shihuang-assembly.1790011920.md
```

- 模型、版本用实际名称，例如 `grok/4.7`。
- 日期目录是 ymd，8 位数字，精确到日，例如 `20260922`。不用中文，不用英文月份。
- 文件名末尾加 unix 秒，同一天多条也不会重名。html 和 md 使用同一个 unix 秒。
- html 是可打开的测试页面。
- md 写明总轮次。每一轮都要有输入提示词，以及该轮 agent 回复的简要结果。
- 新增一条后，把这一条补进 `index.html` 的列表。

## 推送

其他人可以推送。

有写权限时，直接推到 `main`。没有写权限时，发 Pull Request。

推送时带上 html、md，并更新首页索引。路径按上面的规范，不覆盖别人已有的 unix 秒文件。
